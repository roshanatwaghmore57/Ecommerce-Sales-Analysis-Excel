# Ecommerce Sales Analysis – Excel

## Project Overview
An interactive Excel dashboard developed to analyze ecommerce sales data and generate meaningful business insights.

## Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Excel Formulas

## Key Features
- KPI cards for important sales metrics
- Monthly sales trend analysis
- Product category performance analysis
- Sales channel analysis
- Interactive filters and slicers
- Data cleaning and transformation

## Key Insights
- Identified top-performing product categories
- Analyzed monthly sales trends
- Compared sales performance across different sales-channels
- Identified areas contributing to overall sales performance
